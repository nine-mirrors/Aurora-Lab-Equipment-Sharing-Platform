## 2. 作品简介（必填）

极光 · 实验室设备共享平台是一套面向高校实验室的设备共享与智能调度 Web 系统。学生可在大厅检索 14 类设备、查看实时余量与可用日历、在线提交借用申请，凭 6 位取件码取件，并在使用期间续借、归还与评价；管理员可完成审批、归还核验、维护工单、用户与黑名单管理。平台把“申请—审批—取件—续借—归还—评价”串成状态机，库存随审批与归还自动扣减回补；设备报修后自动拦截借用；信用分与黑名单约束逾期行为；站内通知与浏览器推送同步提醒。系统接入通义千问，结合实时库存提供设备推荐与可解释的审批建议，AI 仅作参考，最终决定由管理员完成。作品包含 15 个数据集合、14 个页面、60 个接口、34 项接口测试与 13 项单元/规则测试，可离线一键运行。

## 3. 创意来源（必填）

在实验室做课程实验时，设备信息分散在 Excel、群聊和实验室门口的登记本里：不知道哪台设备空闲、要跑几趟找老师签字、借还记录容易丢失，设备故障后仍可能被预约。我们希望把图书馆的借阅体验搬到实验室——设备像藏书一样可检索、可预约、有档期，借用像借书一样有凭证和到期提醒。基于这个想法，团队设计了以借用状态机为核心的共享平台，并把维护、信用与通知纳入同一闭环；同时引入大模型，让学生在自然语言提问中完成选型与规则查询，让管理员在审批时获得可解释的建议，但保留人工决策权。

## 4. 运行环境（必填）

客户端：Chrome／Edge 等现代浏览器，建议 1440×900 以上分辨率。服务端：Node.js 20.19+ 或 22.12+，使用 npm 安装依赖；无需数据库，数据以 JSON 文件持久化。启动方式：npm install 后执行 npm run dev:all，访问 http://localhost:5173；或执行 npm run build 与 npm run server，单端口访问 http://localhost:3000。AI 问答与邮箱验证码需要外网；未配置 AI 密钥时自动使用本地规则，未配置 SMTP 时验证码在服务端控制台输出（本机演示页可直接看到），不影响功能演示。演示账号：学生 student／123456，管理员 admin／123456。

## 5. AI 使用说明（如系统另有文本框）

已使用。运行时接入通义千问 qwen-flash 与备用 DeepSeek，用于站内问答、审批建议与申请用途草稿；开发阶段使用 AI 编程助手辅助代码片段与文档初稿。所有 AI 输出均经成员核对、修改与测试，业务规则、数据模型、界面与审批决策由学生完成，AI 不参与最终审批。详细说明见《人工智能工具使用情况说明》。

## 6. 接下来在系统里的操作顺序

1. 填写赛道、AI 使用情况、指导教师与参赛学生信息（学校必须从院校库选择）。
2. 填写作品名称、分类、简介、创意来源、运行环境，点击“保存并跳转下一页”。
3. 在承诺书页面核对信息，下载承诺书 → 打印 → 找学校教务处／二级学院／竞赛管理部门盖章 → 扫描为 PDF。
4. 上传材料：
   - （6）参赛承诺书：盖章后的 PDF，1 个文件。
   - （7）作品截图：`submission/screenshots/01-10.jpg`，共 10 张。
   - （8）作品评审视频：上传 `评审视频_极光实验室设备共享平台.mp4`。
   - （9）作品汇报 PPT：上传 `作品汇报PPT.pptx`（与视频同时提交，材料更完整）。
   - （10）参赛打包文件：`极光实验室设备共享平台_参赛打包文件.zip`（内部根文件夹同名，直接上传）。
5. 核对所有栏目后点击【提交审核】，回作品列表确认状态变为“待管理审核”。
